# Chaotic Targeting in Dissipative and Conservative Dynamical Systems--Implications for Low-Energy Transfers
This study explores two classical targeting representations and one data-driven targeting representation. The primary objective is to present representative targeting strategies, develop the associated computational algorithms, and evaluate their performance. This study reconstructs and evaluates three targeting strategies: the Shinbrot method for dissipative sys- tems, Schroer–Ott pass targeting for conservative systems, and the data-driven extended control regions (ECR) method.Together, these methods allow the influence of system structure and targeting strategy on algorithmic performance to be compared, establishing a theoretical and computational basis for algorithm implementation and performance evaluation.
